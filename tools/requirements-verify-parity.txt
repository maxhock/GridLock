# against (federates/grid/requirements.txt, databases/infdb/pyproject.toml),
# not whatever pip resolves as "latest" - an unpinned pandapower here would
# turn the parity check into a pandapower-version diff instead of a check on
# GridLock's own wiring. openpyxl and numba are pandapower optional extras
# ("fileio" and "performance") that pandapower does not install on its own;
# omitting them here previously worked only because something else already
# pulled them into the local dev environment - a fresh CI runner (or a truly
# clean venv) does not have that accident.
#
# cosim-toolbox and helics[cli] are needed too: verify_pandapower_parity.py
# loads federates/grid/main.py by path to reuse sanitize_net_for_power_flow,
# and that module does `from cosim_toolbox.sims import Federate` at import
# time even though this script never calls it - the same accidental-local-env
# gap as openpyxl/numba, just one dependency this fix missed the first time.
