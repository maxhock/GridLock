# 2. Quick Reference - Key Files and Entry Points

## 2.1. Critical Files for Understanding the System

- **Configuration Engine**: `composegen/main.py` - **This is the most critical file.** It reads `config/experiment.yml` and generates the entire simulation setup (`docker-compose.yml` and HELICS configs).
- **Grid Simulator Entry**: `grid/main.py` - The main application logic for the `pandapower` grid federate.
- **Experiment Definition**: `config/experiment.yml` (Assumed) - The high-level file that defines a simulation experiment.
- **Generated Docker Compose**: `config/tmp/docker-compose.yml` (Assumed) - The output of the configuration engine.
- **Generated Grid Config**: `config/helics_grid_config.json` - The HELICS configuration for the grid federate, generated by `composegen/main.py`.
